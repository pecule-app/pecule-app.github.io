Datenschutzerklärung

Zuletzt aktualisiert: 24. Oktober 2026

Kurz gesagt

Pecule erhebt keine personenbezogenen Daten. Es gibt kein Konto, keine Werbung, keine Reichweitenmessung und kein Tracking.

Deine Daten bleiben auf deinem Mac

Deine Konten, Buchungen, Kategorien, Daueraufträge, Anhänge und Sicherungen werden ausschließlich auf deinem Mac gespeichert, in den Dateien, die du wählst. Sie werden an keinen Server gesendet, und wir haben keinen Zugriff darauf.

Importe (CSV, OFX, QIF, PDF-Kontoauszüge) und Exporte (CSV, PDF, Drucken) erfolgen nur auf deinen Wunsch, aus und in die Dateien, die du auswählst.

Netzwerkverbindungen

Die App-Store-Version von Pecule baut keine Netzwerkverbindung auf: Sie funktioniert vollständig offline.

Die direkt auf dieser Website verteilte Version baut zwei Verbindungen auf, die keine Daten deiner Konten oder Buchungen übertragen:

  • die Suche nach Updates (Sparkle) liest die Liste der veröffentlichten Versionen auf GitHub;
  • das Werkzeug Börse fragt Yahoo Finance ab, um die Kurse der Wertpapiere anzuzeigen, die du verfolgst; dabei wird nur das Kürzel des Wertpapiers (zum Beispiel „AAPL“) übertragen. Für diesen Dienst gilt die Datenschutzerklärung von Yahoo.

Weitergabe

Es werden keine Daten geteilt, verkauft oder an Dritte weitergegeben.

Diese Website

Diese Website wird von GitHub Pages bereitgestellt; GitHub kann technische Verbindungsdaten (etwa die IP-Adresse) gemäß seiner eigenen Datenschutzerklärung speichern.

Die Schriften werden von Google Fonts geladen, und der Download-Zähler liest die öffentlichen Release-Statistiken auf GitHub.

Deine Sprachwahl und der letzte Stand des Zählers werden im lokalen Speicher deines Browsers abgelegt. Die Website verwendet keine Cookies und keine Reichweitenmessung.

Änderungen

Diese Seite kann sich ändern; das Datum der letzten Aktualisierung steht oben.
