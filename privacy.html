Pécule

Politique de confidentialité

Dernière mise à jour : 29 octobre 2026

En bref

Pecule ne collecte aucune donnée personnelle. Il n'y a ni compte à créer, ni publicité, ni mesure d'audience, ni traceur.

Vos données restent sur votre Mac

Vos comptes, transactions, catégories, échéances, pièces jointes et sauvegardes sont enregistrés uniquement sur votre Mac, dans les fichiers que vous choisissez. Ils ne sont envoyés à aucun serveur et nous n'y avons pas accès.

Les imports (CSV, OFX, QIF, relevés PDF) et les exports (CSV, PDF, impression) ne se font qu'à votre demande, depuis et vers les fichiers que vous sélectionnez.

Connexions réseau

La version App Store de Pecule n'établit aucune connexion réseau : elle fonctionne entièrement hors ligne.

La version distribuée directement sur ce site établit deux connexions, qui n'envoient aucune donnée de vos comptes ni de vos transactions :

  • la vérification des mises à jour (Sparkle) lit la liste des versions publiées sur GitHub ;
  • l'outil Bourse interroge Yahoo Finance pour afficher le cours des titres que vous suivez ; seul le symbole du titre (par exemple « AAPL ») est envoyé. Ce service est soumis à la politique de confidentialité de Yahoo.

Partage

Aucune donnée n'est partagée, vendue ni transmise à des tiers.

Achat

Pecule s'achète en une fois sur le Mac App Store, sans abonnement. Le paiement est entièrement traité par Apple : nous ne recevons ni votre nom, ni votre adresse e-mail, ni vos informations de paiement ; Apple ne nous communique que des statistiques de ventes anonymes.

La version distribuée sur ce site propose un essai de 30 jours. Pour calculer la durée restante, la date du premier lancement est enregistrée dans le trousseau de votre Mac ; elle n'est envoyée nulle part.

Ce site web

Ce site est hébergé par GitHub Pages ; GitHub peut enregistrer des informations techniques de connexion (comme l'adresse IP) selon sa propre politique de confidentialité.

Les polices de caractères sont chargées depuis Google Fonts, et le compteur de téléchargements lit les statistiques publiques des versions sur GitHub.

Votre choix de langue et le dernier total du compteur sont conservés dans le stockage local de votre navigateur. Le site n'utilise aucun cookie et aucun outil de mesure d'audience.

Modifications
